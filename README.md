# USCL game status (badge data)

This branch only holds the data behind the "USCL online" badges in every branch's README: one file per game
in `badges/<serial>.json` ([shields.io endpoint format](https://shields.io/badges/endpoint-badge)).
Change a game's status by editing its file here; every README shows the new status within a few minutes.

Colours: `brightgreen` works online between PCs · `yellow` testing · `orange` in progress ·
`lightgrey` planned / next up · `inactive` the game has no online mode.
