# Wii Sports + Wii Sports Resort (SP2E01)

Wii disc, USA dual-pack (2010 re-release of Wii Sports 2006 + Wii Sports Resort 2009). Profiled 2026-11-07.
Emulator: **Dolphin** (Flatpak `org.DolphinEmu.dolphin-emu` 2609a). Platform notes: `uscl-dolphin/`.
Dump: `~/Downloads/GAME_DUMPS/WII/Wii Sports + Wii Sports Resort (USA) (En,Fr,Es)/*.wbfs` (1.1 GB, WBFS, id `SP2E01`).

## Online service
**None — the game has no online multiplayer.** Both titles are couch-only (2–4 players sharing Wii Remotes on one
console). There is no publisher server (no Nintendo Network, Demonware, or Blaze), so there is nothing to revive.

Online is instead provided by **Dolphin NetPlay** over the USCL Steam tunnel: NetPlay runs the game in lockstep on
both PCs and syncs the **full Wii Remote input** (buttons, IR, accelerometer, MotionPlus), which is what makes the
motion gameplay work across the tunnel. See `uscl-dolphin/README.md` for the mechanism and the motion-source options.

## Status (2026-11-07): emulator boots the game
Dolphin 2609a boots `SP2E01` with the Vulkan backend (JIT64) to the dual-pack's **"Which game would you like to
play?"** menu (Wii Sports / Wii Sports Resort), with an emulated Wii Remote pointer active. So the platform runs on
this machine; the online layer is next.

The USCL side is ready: `uscl-bridge` has a `dolphin` forward preset (`tcp:2626`, Dolphin's NetPlay port) with a
parse test. Nothing game-specific is needed — Wii Sports is just the first game to drive the Dolphin path.

## Motion setup (per player)
Easiest: a **PS5 DualSense** (or DS4 / Switch Pro) — Dolphin 2609a reads its gyro+accelerometer **natively** (no DSU
server) and you bind it to the emulated Wii Remote's Motion Input; Wii Sports is mostly accel swings, so it maps
naturally (tune sensitivity). Or a real Wii Remote via **Bluetooth passthrough** (most accurate, MotionPlus detected).
Phone gyro via DSU/cemuhook is the fallback. Details in `uscl-dolphin/README.md`.
