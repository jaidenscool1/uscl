Title ID: `0100152000022000`. Base-game container found locally; filename indicates v0. Title/version metadata has not been verified by decrypting the container. The local update and Booster Course archives are separate content, installed through Eden rather than imported as launchable games.

USCL route: Eden local wireless (LDN), with an Eden room on host loopback UDP 24872 transported to session members by `uscl-bridge host switch`. Start or join the Steam session before launching the game, then choose Wireless Play in the game. Every player needs matching emulator, game-update and DLC versions.

Implemented: library scan, Switch core selection, isolated profile, console-file import UI, automatic CLI room join, room-server lifecycle, and Steam UDP forwarding preset. The default route does not start PS3 services.
