# Minecraft: PlayStation 3 Edition (BLUS31426)

`np-profile.py`: FULL. Matching2 27, Manager 11, Score 10, Basic 9, Lookup 9, Commerce2 32, Trophy 11.

## How it finds games
**1.84 (the version to play):** the join list polls `GetServerList` → `GetWorldList` → `SearchRoom` every few
seconds (seen on the host RPCN, 2026-10-22). Both players must be on the same version.

1.00 disc build: no `sceNpMatching2SearchRoom` import. Worlds are found through friends: `sceNpBasicGetFriendPresenceByIndex`
reads friends' presence (set with `sceNpBasicSetPresenceDetails`), then `GetRoomDataExternalList` + `JoinRoom`
by room ID. Invites: `sceNpBasicSendMessageGui` / `sceNpBasicRecvMessageCustom`.
So friends + presence matter more than lobby search for this game.
