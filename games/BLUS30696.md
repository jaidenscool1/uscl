# NBA Jam (BLUS30696)

Disc 1.00 (EBOOT built Sep 27 2010). Profiled 2026-11-06 on the uscl-rpcs3 rebase (upstream eee3f0f): boots to the
title and menus, picture correct, first boot compiles for ~5 min, then about 12 s to the main thread.

## How it plays online
EA **Blaze**, BlazeSDK `2.11.4.1` (same era as Skate 3's), through RPCN for the PSN side:
| What | Where |
|---|---|
| login proof | `sceNpManagerRequestTicket2`, service `UP0006-BLUS30696_00`: an RPCN ticket. Needs PSN status **RPCN** (Simulated stops the game: "RPCN is required to use PSN online features") |
| redirector | `gosredirector.ea.com` TCP **42100, plain (no TLS)** |
| Blaze server | whatever the redirector returns (`standardSecure` profile, so normally SSL) |
| QoS / NAT checks | HTTP `/qos/qos`, `/qos/firewall`, `/qos/firetype`, `getPeerAddress`, on the addresses Blaze hands out |
| UPnP | DirtySock probes the router (`192.168.1.1:5000`) at startup, harmless |

The redirector request, captured at Main menu → Play Online (421 bytes, Blaze header `0199 0005 0001 ...`:
component 5 Redirector, command 1 getServerInstance) carries `2.11.4.1`, `JAM` / `JAM_PS3`, env `prod`,
service name **`nbajam-2010-ps3`**, connection profile `standardSecure`, and the RPCN ticket for the signed-in
user. With nothing answering, the game says "The EA servers are not available at this time".

Hosts the EBOOT names (all go in the IP swap list): `gosredirector.ea.com`, `gosredirector.online.ea.com`,
`gosredirector.scert.ea.com`, `gosredirector.stest.ea.com`, `peach.online.ea.com`, `demangler.ea.com`.

## Plan
1. **Try Skate3BlazeServer first.** Its redirector ignores the service name and returns itself with `SECU = 0`
   (no SSL), and it already accepts RPCN tickets. Point NBA Jam at a local one and see how far the login gets
   (PS3 login, then user session / game manager components). Skate 3 and NBA Jam are both 2010 BlazeSDK 2.x.
2. Whatever it lacks for NBA Jam (title-specific components, the game manager's game types) goes into USCL's own
   Blaze stand-in (PLAN.md phase 6). That code can't come from Skate3BlazeServer (no license); the MIT
   Aim4kill/BlazeSDK is the base to use.
3. Game traffic: find out whether matches are peer to peer (then the session tunnel carries them) or relayed.

Probe setup on jaiden-pc: config `~/.local/share/uscl/rpcs3-ea-probe` (RPCN account uscltest, IP swap list with
every EA name above to 127.0.0.1, virtual pad "Xbox 360 Controller 2"); `tools/autotest/vpad.py` drives the menus.
