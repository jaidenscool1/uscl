# LittleBigPlanet 3 (BCUS98362)

Disc 1.02 (Sony first-party). Profiled 2026-11-07.

## Online service
**PSN only** — the EBOOT shows no publisher server, just the PSN update CDN. LBP games use Sony's matchmaking
(sceNpMatching2 rooms + signaling) for their online (create/join levels, pods), which **RPCN implements directly**.
So LBP3 should work through RPCN with no custom server, like Minecraft (BLUS31426) — needs a boot test to confirm
it reaches online and two copies can see each other.

## Status (2026-11-07): boots and connects to RPCN
Booted on the rebased RPCS3 with `PSN status: RPCN`: installs its game data, runs (intro → pod), takes input, and
**connects to RPCN** (`connect: Connection successful / Handshake successful / Protocol version matches / Attempting
to login`). Confirms LBP3 is RPCN-compatible at the network layer, like Minecraft.

Caveat: LBP3 has two separate online pieces. **Player multiplayer** (join a friend's pod, co-op levels) uses PSN
**Matching2** rooms + signaling, which RPCN carries — this should work. The **Community level browser** (download
user-made levels, LBP.me) used Sony's content/database servers, which are dead and not part of RPCN; that part
won't come back without those servers.
