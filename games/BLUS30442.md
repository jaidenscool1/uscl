# Midnight Club: Los Angeles (BLUS30442)

Complete Edition, disc 1.03 (app 1.06). Re-profiled 2026-11-07: the online is **GameSpy**, not Rockstar's own
servers (the earlier memory note was wrong).

## Online service
**GameSpy** (shut down 2014, revived by the OpenSpy community) — the same stack as Gotham City Impostors
(`games/NPUB30252.md`, `sirenps3`):
| What | Where |
|---|---|
| login / presence | `gpcm.gamespy.com`, `gpsp.gamespy.com` |
| server browser / master | `s.master.gamespy.com`, `s.available.gamespy.com` |
| NAT negotiation | `natneg1/2/3.gamespy.com` |
| auth / competition / storage | `s.auth.pubsvs.gamespy.com`, `s.comp.pubsvs.gamespy.com`, `s.sake.gamespy.com` (Sake: leaderboards, record storage) |

## Plan
Reuses the GameSpy revival work being done for Gotham City Impostors (OpenSpy-style server + the SSLv3 GameSpy
login). GCI is the test game for that; MCLA follows once GCI's GameSpy login is solved. MCLA also needs Sake
(leaderboards/ghost storage) which GCI may not — add it when MCLA is tackled.
