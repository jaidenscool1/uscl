# Skate 3 (BLUS30464)

`np-profile.py`: PARTIAL (disc 1.00, profiled 2026-10-23). Basic 14, Manager 11, Lookup 9, Commerce2 28, Trophy 9.
No Matching2, no Signaling. Also imports `sys_net`, `cellHttp`, `cellSsl`, `cellNetCtl`: it talks to its own servers.

## How it plays online
Everything multiplayer goes through EA's Blaze protocol, now served by the community **Skate3BlazeServer**
(public server, or self-hosted; the game reaches it through RPCS3's IP swap list):
| What | Where |
|---|---|
| login, lobbies, matchmaking (Blaze) | server TCP 42100 |
| profiles, reels, feeds (`*.asmx`) | server HTTP TCP 80 |
| game traffic | server UDP relay, one port per lobby: 17000 + game id. The relay tells players apart by source address |
| invites, friends | PSN: `sceNpBasicSendMessageGui` / `RecvMessageCustom`, i.e. RPCN |
| login proof | `sceNpManagerRequestTicket2`: an RPCN ticket, which the community server accepts |

So no game traffic is peer to peer through RPCS3's P2P socket. The session tunnel as it is carries only the
invites.

Prerequisites everyone needs (from the skate3-rpcs3-online repo): 1.05 + the configEditor online EBOOT, and the
same physics/timing settings (`show` fingerprint), or players drop out of each other's lobby.

## Plan
1. **Server over the tunnel (next).** The host runs the community server on their PC, built from upstream. USCL
   doesn't ship it, since it has no license. The bridge forwards its ports over Steam: each member's
   127.0.0.1:42100 / :80 / UDP 17001–17064 go to the host's server. Members set their IP swap list to
   127.0.0.1. That replaces Tailscale and port forwarding, works on any OS, and allows any lobby size. The host
   side must use one UDP socket per member per relay port, because the relay identifies players by address.
   Problem: binding 127.0.0.1:**80** needs privileges on Linux (macOS and Windows allow it). Options: a
   uscl-rpcs3 patch that lets the IP swap list remap a port, or `setcap` on the bridge. The patch is preferred.
2. Invites stay on the host's RPCN (already tunnelled). Later: Steam invite → in-game invite.
3. PLAN.md phase 6 (Blaze-over-Steam, no server at all) only once 1 works.
